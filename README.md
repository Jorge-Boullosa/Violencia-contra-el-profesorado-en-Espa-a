# Violencia-contra-el-profesorado-en-España
En este proyecto, con la colaboración de ADEC Pontevedra, se analiza la violencia contra el profesorado: tipos, frecuencia y factores asociados. Para ello se aplica estadística descriptiva y un modelo de regresión logística binaria que estima la probabilidad de sufrir violencia según distintas variables personales y laborales.

## Objetivo del proyecto

El objetivo principal es estudiar qué factores pueden estar relacionados con la probabilidad de que un docente sufra algún tipo de violencia en su entorno profesional.

A partir de una base de datos sobre profesorado, se analizan variables personales, profesionales y del centro educativo para construir un modelo explicativo mediante regresión logística binaria.

## Variables analizadas

Las principales variables incluidas en el análisis son:

- Sexo.
- Nivel educativo.
- Tipo de centro.
- Zona.
- Edad.
- Experiencia docente.
- Existencia y calidad de protocolos que eviten o ayuden como actuar en caso de violencia.
- Presencia o ausencia de violencia.

## Técnicas utilizadas

- Estadística descriptiva.
- Análisis de frecuencias.
- Regresión logística binaria.
- Interpretación de coeficientes y odds ratios.
- Análisis ceteris paribus.
- Tabla de clasificación.
- Prueba de Hosmer-Lemeshow.
- Bootstrap.
- Revisión de posibles valores atípicos.

## Herramientas

- SPSS.
- R.
- Excel.
- PowerPoint.

## Principales resultados

El modelo permite estudiar qué variables presentan mayor asociación con la probabilidad estimada de sufrir violencia. Uno de los resultados más relevantes es que una mayor calidad o presencia de protocolos en el centro se asocia con una menor probabilidad estimada de sufrir violencia.

El modelo clasifica correctamente el 61,3% de los casos, por lo que debe interpretarse como una aproximación exploratoria al fenómeno analizado.

## Recomendaciones

A partir de los resultados obtenidos, se plantean varias líneas de actuación:

- Crear o mejorar los protocolos de actuación en los centros educativos.
- Desarrollar programas de apoyo para docentes jóvenes o recién incorporados.
- Diseñar medidas de protección con enfoque de género.
- Impulsar formación continua sobre gestión de conflictos.
- Promover talleres de sensibilización y alfabetización emocional para el alumnado.

## Limitaciones

Este trabajo debe interpretarse con prudencia. El modelo permite identificar asociaciones entre variables, pero no establecer causalidad directa. Además, la capacidad predictiva podría mejorar con una muestra más amplia, nuevas variables explicativas o técnicas complementarias de validación.
